# 武汉民生与涉企诉求线索归集

公开网络线索归集：每 12 小时扫描武汉市官方诉求平台与公开投诉渠道，按规则筛选后条目化输出，可溯源、不编造。

- **在线看板**：https://anywise666.github.io/wuhan-civic-leads/
- **数据**：公开页面采集，投诉人已脱敏；已剔除官方/官媒公开且明确办结的事项
- **说明**：仅反映公开页面记载，不构成对事实的最终认定

## 目录

| 路径 | 内容 |
|---|---|
| `index.html` | 看板页面（Pages 从根目录发布） |
| `规则/` | 采集与核验规则、来源清单、运行提示词 |
| `工具/` | 看板生成、台账导出、线上推送脚本 |
| `数据/` | 线索台账（JSONL）、剔除记录（JSONL） |
| `报告/` | 每期归集报告（Markdown）；`进度.md` 为跨机接力的当前进度 |

## 工作流

1. 智能体读取 `规则/` 与 `数据/`；
2. 抓取市政府/委办局来信公示、武汉城市留言板、人民网领导留言板、黑猫投诉等公开渠道；
3. 逐条核验、去重、判定状态，只保留未办结/处理中/已回复未办结/办结不满意；
4. 写 `报告/`、追加 `数据/线索台账.jsonl`、重新生成 `index.html`；
5. 推送到本仓库，GitHub Pages 自动重建。

## 本地命令

```bash
python 工具/生成看板.py     # 台账 -> 看板
python 工具/导出台账.py     # 台账 -> CSV/汇总
python 工具/更新线上.py     # 推送看板、规则、数据与报告到本仓库
```

## 安装到桌面（PWA，可选）

看板支持 PWA：装到桌面后全屏无地址栏，首次联网打开过后可离线查看。浏览器支持情况（2026-11 实测）：

| 浏览器 | 安装方式 | 结果 |
|---|---|---|
| iOS Safari | 分享 → 添加到主屏幕 | ✅ 可用（已实测） |
| 小米自带浏览器 | 页面「安装到桌面」/ 浏览器菜单 | ✅ 可用（已实测） |
| 荣耀 / 华为自带浏览器 | 菜单无「添加到桌面」，不弹安装框 | ❌ 不支持（版本阉割） |
| Chrome / Edge（Chromium） | ⋮ → 安装应用 | ✅ 预期可用 |
| 微信 / QQ 内置浏览器 | 无安装入口 | ❌ 需先「在浏览器打开」 |
| OPPO / vivo / 三星自带 | 菜单查找「添加到桌面」 | ⏳ 待测 |

页面顶部有「安装到桌面」按钮：浏览器支持时弹原生安装框，不支持时按机型弹出操作指引。

荣耀/华为替代：书签保存，或改用 Edge（国内应用商店可下，Chromium 内核，支持安装 PWA）。

布局自适应：手机单列卡片（≤760px）、平板双列卡片（761–1080px，含 iPad 竖屏与多数安卓平板）、桌面表格（>1080px）。

## 访问不畅时怎么办

GitHub Pages 在国内部分网络会间歇性打不开。**已核实：jsDelivr 对 HTML 返回 `text/plain; nosniff`，浏览器只显示源码、不渲染页面，不能当镜像用**（2026-11-27 实测）。

可用方式：

1. 稍后重试——多数是短时抖动；
2. 已安装 PWA 的设备：首次联网打开过后可离线查看；
3. 向分享者索取 `index.html` 文件，双击即用；
4. 长期稳定需国内托管（CloudBase / COS + 备案域名）。
